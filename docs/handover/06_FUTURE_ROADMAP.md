# Mnemosyne Future Roadmap 🗺️

---

## 🌟 Milestone 1: HTTP / SSE Transport Gateway (v3.2)
* Support remote agents over Server-Sent Events (SSE) and HTTP POST.
* Add Bearer Token authentication for multi-agent cloud deployments.

---

## 🌟 Milestone 2: Obsidian Plugin & Web Visualizer (v3.3)
* Native Obsidian Community Plugin that embeds the Mnemosyne query bar directly into Obsidian.
* Web-based 3D graph visualizer with live memory node clustering.

---

## 🌟 Milestone 3: Cross-Agent Memory Synthesis (v3.4)
* Inter-agent memory sharing protocols allowing specialized agents (e.g. Pentest agent sharing discovered CVEs with DevOps agent).
