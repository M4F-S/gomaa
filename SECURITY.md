# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.5.x   | :white_check_mark: |
| < 3.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or credential leak vector within Gomaa, please **do not open a public GitHub issue**.

Instead, please report security issues privately:
1. Use GitHub's private vulnerability reporting feature under the **Security** tab of this repository.
2. Provide a detailed summary, steps to reproduce, and proof of concept if applicable.

We acknowledge receipt of vulnerability reports within 48 hours and work diligently to release patches for confirmed issues.
