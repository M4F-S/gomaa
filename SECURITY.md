# 🔒 Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.0.x   | :white_check_mark: |
| 3.5.x   | :white_check_mark: |
| < 3.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or credential leak vector within Gomaa, please **do not open a public GitHub issue**.

Instead, please report security issues privately:
1. Use GitHub's **[Private Vulnerability Reporting](https://github.com/M4F-S/gomaa/security/advisories/new)** feature under the **Security** tab of this repository.
2. Provide a detailed summary, steps to reproduce, impact assessment, and proof of concept if applicable.

We acknowledge receipt of vulnerability reports within 48 hours and work diligently to verify, triage, and release patches for confirmed issues.
